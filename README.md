# API Testing Fake Store

Учебный проект по автоматизированному тестированию REST API сервиса [Fake Store API](https://fakestoreapi.com).

## Что проверяется

- GET-запросы для получения списка продуктов
- GET-запрос продукта по id
- POST-запрос для создания нового продукта
- Проверка status code
- Проверка response body
- Проверка обязательных полей
- Негативные сценарии с невалидными данными
- Проверка времени ответа

## Тестовая документация

В проекте также подготовлена тестовая документация для раздела **Products**:

- описаны тест-кейсы для проверки API Products
- оформлены баг-репорты по найденным дефектам
- добавлена Postman-коллекция с запросами для ручной проверки API

## Технологии

- Java
- Maven
- JUnit 5
- REST Assured
- Hamcrest
- Postman

## Цель проекта

Закрепить навыки API-тестирования, работы с HTTP-запросами, написания автотестов, оформления тестовой документации, создания баг-репортов и работы с Postman-коллекциями.
